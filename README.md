# YasserMind

I build applied machine-learning, NLP, and data-analysis projects, with interactive applications that make the work easier to explore.

## Project directory

| Area | Project | Explore |
|---|---|---|
| Arabic NLP and search | **[Arabic Poetry Semantic Retrieval](https://github.com/altayariyasser/arabic-poetry-semantic-retrieval)** | Arabic verse retrieval with pretrained multilingual E5, BM25, cosine similarity, RRF, and an Arabic Gradio interface |
| Financial ML and NLP | **[GrowthLens](https://github.com/altayariyasser/GrowthLens)** | Company discovery and annual-filing research, with an interactive React workspace, research notebook, report, and demo |
| Energy and environmental analytics | **[SolarIQ](https://github.com/altayariyasser/SolarIQ)** | Solar-generation and air-quality analytics, predictive models, retrieval-assisted analysis, and interactive dashboards |
| Classification and exploratory analysis | **[Student Lifestyle and Depression Classification](https://github.com/altayariyasser/Depression_Project)** | Lifestyle-data exploration, logistic regression, random forests, PCA comparisons, and a Streamlit application |

## Tools across these projects

Python · Jupyter · pandas · NumPy · scikit-learn · PyTorch · Transformers · Gradio · Streamlit · React

Each repository documents its own data access, setup, methodology, results, and limitations. The poetry project uses pretrained E5; its corpus and embedding indexes require separate authorized access.
